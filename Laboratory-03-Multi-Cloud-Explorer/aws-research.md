# Amazon Web Services (AWS) Research

## 1. Brief Overview

Amazon Web Services (AWS) is a cloud computing platform provided by Amazon. I learned that AWS provides many different cloud services such as computing, storage, databases, networking, security, and artificial intelligence. AWS allows organizations to use computing resources through the internet instead of maintaining all of their own physical infrastructure.

## 2. Global Infrastructure

AWS has a global infrastructure made up of Regions and Availability Zones. A Region is a separate geographic area, while Availability Zones are isolated locations within a Region. This infrastructure helps organizations build applications that can be available and reliable in different locations.

## 3. Cloud Management Console

The AWS Management Console is a web-based interface used to manage AWS services. I can use the console to create resources, configure services, monitor resources, and manage my cloud infrastructure.

## 4. Four Core Services

### Amazon EC2

Amazon Elastic Compute Cloud (EC2) provides virtual servers that can be used to run applications and other workloads.

### Amazon S3

Amazon Simple Storage Service (S3) is an object storage service used to store files, data, backups, and other information.

### Amazon RDS

Amazon Relational Database Service (RDS) provides managed relational databases.

### AWS IAM

AWS Identity and Access Management (IAM) allows organizations to manage users, permissions, and access to AWS resources.

## 5. Three Advantages

1. AWS provides a wide range of cloud services.
2. AWS has a global infrastructure that can support applications in different locations.
3. AWS allows organizations to scale their resources based on their needs.

## 6. Typical Enterprise Use Cases

AWS can be used by organizations for:

- Web applications
- Mobile applications
- E-commerce systems
- Database hosting
- Data storage and backup
- Artificial intelligence and machine learning
- Disaster recovery
- Enterprise applications
