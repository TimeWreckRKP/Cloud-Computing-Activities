# Microsoft Azure Research

## 1. Brief Overview

Microsoft Azure is Microsoft's cloud computing platform. I learned that Azure provides cloud services for computing, storage, databases, networking, security, artificial intelligence, and application development.

## 2. Global Infrastructure

Azure has a global infrastructure made up of regions and datacenters around the world. This infrastructure allows organizations to deploy applications closer to their users and helps support availability, performance, and data residency requirements.

## 3. Cloud Management Console

The Azure Portal is a web-based management interface for Microsoft Azure. I can use it to create, configure, manage, and monitor Azure resources.

## 4. Four Core Services

### Azure Virtual Machines

Azure Virtual Machines allow organizations to create and run virtual machines in the cloud.

### Azure Blob Storage

Azure Blob Storage is an object storage service used to store large amounts of unstructured data.

### Azure SQL Database

Azure SQL Database is a managed relational database service.

### Microsoft Entra ID

Microsoft Entra ID provides identity and access management for users and applications. It can also work with Microsoft services and organizational environments.

## 5. Three Advantages

1. Azure has strong integration with Microsoft technologies.
2. Azure provides a large global infrastructure.
3. Azure provides many services for enterprise computing, security, databases, and artificial intelligence.

## 6. Typical Enterprise Use Cases

Azure can be used for:

- Windows Server migration
- Enterprise applications
- Database hosting
- Virtual machines
- Microsoft-based environments
- Artificial intelligence
- Hybrid cloud environments
- Business applications

## My Observation

After researching Azure, I learned that it is especially useful for organizations that already use Microsoft technologies. I think Azure would be a good choice for companies and universities that already use Windows Server, Microsoft 365, and Microsoft identity services.
