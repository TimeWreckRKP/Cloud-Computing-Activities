# Reflection

After completing this Cloud Computing mission, the cloud platform that impressed me the most was AWS. I chose AWS because it has many different services that can be used for computing, storage, databases, networking, and other needs. As an IT student, I also think learning AWS can help me gain useful knowledge that I can apply to future projects and work.

I noticed that AWS, Azure, and Google Cloud Platform have many similarities. All of them provide services for virtual machines, storage, networking, databases, and security. They allow users and organizations to use computing resources through the internet without having to depend completely on physical servers. Even though they have similar services, each platform has its own strengths.

Business requirements are important when choosing a cloud platform. I learned that the best platform depends on what the organization actually needs. For example, I recommended Azure for the university because it already uses Microsoft technologies. I recommended Google Cloud for the AI research company because it is strong in Artificial Intelligence, Machine Learning, and Kubernetes. AWS was a good choice for the startup and global e-commerce company because of its flexibility, scalability, and wide range of services.

Acting as a Cloud Solutions Consultant helped me understand how to compare cloud platforms and choose one based on a client's needs. I learned that I should consider the budget, existing technology, performance, scalability, and goals of the organization before making a recommendation.

My GitHub Cloud Computing Portfolio also improved because I was able to organize my research, comparisons, client recommendations, decision matrix, and Linux lab results in one repository. I also learned how to document my work and use GitHub to present my activities. Overall, this mission helped me understand cloud computing better and gave me experience in making cloud-related decisions.
