# Google Cloud Platform (GCP) Research

## 1. Brief Overview

Google Cloud Platform (GCP), also called Google Cloud, is Google's cloud computing platform. I learned that Google Cloud provides services for computing, storage, databases, networking, containers, data analytics, artificial intelligence, and machine learning.

## 2. Global Infrastructure

Google Cloud uses regions and zones around the world. A region is a geographic location that contains multiple zones. Organizations can choose locations based on requirements such as performance, availability, and data location.

## 3. Cloud Management Console

The Google Cloud Console is a web-based management interface. I can use it to create, configure, monitor, and manage Google Cloud resources.

## 4. Four Core Services

### Compute Engine

Compute Engine provides virtual machines that can be used to run applications and other workloads.

### Cloud Storage

Cloud Storage provides object storage for files, backups, and other types of data.

### Cloud SQL

Cloud SQL is a managed relational database service that supports database systems such as MySQL and PostgreSQL.

### Google Kubernetes Engine

Google Kubernetes Engine (GKE) provides a managed environment for running containerized applications using Kubernetes.

## 5. Three Advantages

1. Google Cloud has strong artificial intelligence and machine learning capabilities.
2. Google Cloud provides strong support for Kubernetes and containerized applications.
3. Google Cloud uses Google's global infrastructure and networking.

## 6. Typical Enterprise Use Cases

Google Cloud can be used for:

- Artificial intelligence and machine learning
- Data analytics
- Containerized applications
- Web applications
- Database hosting
- Big data processing
- Global applications

## My Observation

After researching Google Cloud, I learned that it is strong in artificial intelligence, machine learning, data analytics, and Kubernetes. I think it would be a good choice for organizations that develop modern applications and AI-based systems.
