# Laboratory 05 - The Cloud Data Engineer

## Mission Overview

In this laboratory activity, I worked as a Cloud Data Engineer and learned how cloud storage can be used to store large amounts of data. I deployed a MinIO S3-compatible Object Storage server using Docker, accessed its Web Console, created a storage bucket, and uploaded a test file.

## Objectives

The objectives of this laboratory were:

- Differentiate Block Storage, File Storage, and Object Storage.
- Deploy an S3-compatible Object Storage server using Docker.
- Access a cloud service through a web browser.
- Create a storage bucket.
- Upload an object to the bucket.
- Document the cloud storage deployment using Markdown.
- Add the activity to my GitHub Cloud Computing Portfolio.

## Tools Used

- KillerCoda Playground
- Ubuntu

- MinIO
- GitHub

## Skills Learned

Through this activity, I learned how different types of cloud storage are used for different purposes. I also learned how to deploy a containerized storage server using Docker and configure it using environment variables.

I practiced accessing a service through a specific port and using a web-based management console. I also learned how to create an Object Storage bucket and upload files to it.

Another skill I improved was documenting technical work using Markdown and organizing my laboratory files and screenshots in GitHub.
